# Imagens da Ampla Distribuidora

Imagens públicas usadas nos e-mails da Ampla Distribuidora (app Ampla Disparo, ALC Info).
Servidas pelo GitHub Pages em `https://andrechita.github.io/ampla-imagens/<arquivo>`.

- `apresentacao.jpg`: banner do e-mail de apresentação (1200×625).

Para trocar uma imagem: mantenha o mesmo nome de arquivo (os e-mails já enviados apontam para ele) ou crie um nome novo.
